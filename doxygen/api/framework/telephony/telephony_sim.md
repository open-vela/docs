# Telephony SIM API

Telephony SIM TAPI 提供 openvela Telephony 处理 SIM 卡（包括 STK）相关业务。APP 无需关心 SIM 卡模块的内部业务细节，仅需调用 API 获取 SIM 信息或者监听 SIM 相关消息即可完成 APP 开发。
