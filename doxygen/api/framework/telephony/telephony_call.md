# Telephony Call API

Telephony Call TAPI提供Vela Telephony处理通话相关业务，以及补充业务相关业务能力，包括会议通话、呼叫转移、呼叫等待、呼叫限制等。APP无需关心CALL模块的内部业务细节，仅需调用API获取CALL信息或者监听CALL相关消息即可完成APP开发。
