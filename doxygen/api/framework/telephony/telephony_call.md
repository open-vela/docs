# Telephony Call API

Telephony Call TAPI 提供 openvela Telephony 处理通话相关业务，以及补充业务相关业务能力，包括会议通话、呼叫转移、呼叫等待、呼叫限制等。APP 无需关心 CALL 模块的内部业务细节，仅需调用 API 获取 CALL 信息或者监听 CALL 相关消息即可完成 APP 开发。
