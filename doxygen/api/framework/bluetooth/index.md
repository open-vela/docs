# Bluetooth

本章节详细介绍 **openvela** 系统中蓝牙协议栈的开发与配置。文档涵盖了从基础的连接管理（GAP/GATT）到各类经典蓝牙应用规范（Profiles）的实现细节。

开发者可通过以下文档了解各个协议的具体用法：

- **基础核心**：GAP（通用访问规范）、GATT（通用属性规范）。
- **音频与控制**：A2DP（高级音频分发）、AVRCP（音视频远程控制）、HFP（免提规范）。
- **外设与数据**：HID（人机接口设备）、SPP（串口仿真）、PAN（个人局域网）。
