# Feature Framework API

Feature 框架是 openvela 快应用（Quick App）的 Native 扩展开发框架，提供 JS 与 C/C++ 之间的互调能力。开发者可以通过 Feature 框架为快应用扩展新的系统能力，框架负责参数转换、生命周期管理、异步编程模型以及接口自动生成（JIDL）等核心功能。
