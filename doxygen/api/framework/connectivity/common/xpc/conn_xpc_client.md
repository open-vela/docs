# 连接服务 XPC 客户端 (Conn XPC Client) API 开发指南

**Conn XPC Client** 模块是应用程序与系统连接服务交互的客户端库。它封装了底层的 IPC 传输细节，为上层应用提供了一套标准的 C 语言接口，用于发起连接请求、发送控制命令以及接收服务端的异步事件。

在系统架构中，该模块通常作为静态库或动态库链接到应用程序中，负责处理以下任务：

- **会话管理**：维护与连接服务守护进程（Daemon）的连接状态（重连、心跳等）。
- **消息封装**：将应用程序的 API 调用打包成符合协议规范的消息。
- **响应分发**：接收服务端的回复，并将其路由到相应的回调函数。

## 1. API 接口概览

该模块包含核心客户端逻辑及消息协议定义两部分。

### 1.1 客户端核心逻辑

`conn_xpc_client.h` 定义了客户端的生命周期管理及传输接口。

- **核心功能**：

    - **客户端初始化**：配置客户端环境，建立与服务端的 IPC 通道。
    - **同步/异步调用**：提供阻塞（等待响应）和非阻塞（仅发送）的接口模式。
    - **事件循环集成**：如果适用，提供文件描述符以便集成到应用的主事件循环中。

### 1.2 消息协议定义

`conn_xpc_client_msg.h` 定义了客户端与服务端通信的具体“语言”，即消息载体（Payload）的结构。

- **核心功能**：

    - **消息结构体**：定义 Wi-Fi、蓝牙等具体业务的命令参数结构（如 `struct wifi_scan_params`）。
    - **操作码 (OpCode)**：定义不同业务请求的唯一标识符。
    - **序列化/反序列化**：定义消息在传输过程中的打包与解包规则（如果包含在此文件中）。
