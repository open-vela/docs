# 连接服务通信 (Conn XPC) API 开发指南

**连接服务通信 (Connectivity XPC)** 模块提供了连接子系统的跨进程通信接口。它作为应用层（Client）与底层连接服务（Service/Daemon）之间的桥梁，封装了底层的 IPC 细节，使得上层应用能够以函数调用的方式控制连接设备并接收状态更新。

该模块主要解决以下问题：

- **进程隔离**：允许应用程序与运行在不同进程空间的连接服务进行安全通信。
- **命令分发**：将上层的控制指令（如打开 Wi-Fi、扫描蓝牙）序列化并发送至服务端。
- **事件订阅**：处理服务端的异步回调（如连接断开、扫描结果），并将其分发给订阅者。

## 1. API 接口概览

`conn_xpc_api` 提供了初始化通信通道、发送指令及注册回调函数的接口。

### 1.1 通用通信接口

`conn_xpc_api.h` 定义了 XPC 的核心操作，主要面向需要直接与连接守护进程交互的组件。

- **核心功能**：

    - **初始化 (Init/Deinit)**：建立或销毁与连接服务的 IPC 通道。
    - **消息发送 (Send Message)**：向连接服务发送控制指令或配置参数。
    - **回调注册 (Register Callback)**：注册监听器，用于接收连接状态变化、扫描结果等异步事件。
