# 连接服务通信 (XPC) 概述

**连接服务通信 (Connectivity Cross-Process Communication, XPC)** 模块是连接子系统的核心通信骨架。它建立在系统底层 IPC 机制之上，提供了一套标准化的框架，用于在**应用层客户端 (Client)** 与**后台服务进程 (Server)** 之间传递控制指令和状态事件。

本模块通过定义统一的协议接口，实现了业务逻辑与通信细节的解耦，确保了连接服务的高效、安全与稳定运行。

## 架构组件

XPC 框架由以下三个主要部分组成：

1. **通用接口 (API)**: 定义了通信的基础协议、公共数据结构及接口规范，是客户端和服务端共同遵守的契约。
2. **客户端 (Client)**: 运行在应用进程中，负责将用户的 API 调用转化为 IPC 消息发送给服务端，并处理回调。
3. **服务端 (Server)**: 运行在守护进程中，负责监听请求、分发任务至具体业务模块（如 Wi-Fi/BT 协议栈），并广播状态变化。
