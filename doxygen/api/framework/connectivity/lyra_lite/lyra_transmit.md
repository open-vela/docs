# Lyra Lite 传输通道管理 API 开发指南

**Lyra Lite 传输通道管理 (Transport Channel Management)** 模块构建了设备间高效、可靠的数据传输管道。

该模块位于应用层与底层链路之间，旨在屏蔽底层物理传输的限制（如 MTU 大小限制）。它负责处理大数据的自动分包与重组（Segmentation & Reassembly）、传输流控以及数据缓冲管理。通过该模块，应用层可以专注于业务逻辑数据的收发，实现高吞吐量的透明传输，而无需关注底层的数据切片或丢包重传细节。

## 1. 接口概览

本模块致力于优化数据传输体验，核心功能包括：

- **透明传输**：自动处理长包数据，支持发送超过单次空中包长限制的数据块。
- **传输策略**：提供不同的传输模式（如高吞吐量模式或低延迟模式），以适应不同的业务场景。
- **流控与缓冲**：内部维护发送/接收队列，提供传输状态（完成/失败）回调，防止在弱网或高并发环境下数据溢出。
- **通道隔离**：支持管理不同的逻辑数据通道，确保控制指令与大容量用户数据互不干扰。
