# Lyra Lite SDK 初始化 API 开发指南

**Lyra Lite SDK 初始化 (SDK Initialization)** 模块是整个软件系统的入口与基石。

它负责在应用层逻辑启动之前，完成底层硬件抽象层 (HAL)、蓝牙协议栈、内存堆栈以及系统后台服务任务的配置与加载。正确地初始化 SDK 是确保广播、连接、组网等上层功能正常运行的先决条件。同时，该模块也提供了资源释放机制，支持系统的软重启或低功耗模式切换。

## 1. 接口概览

本模块主要负责 SDK 全局生命周期的管理，核心功能包括：

- **系统启动**：加载蓝牙协议栈，初始化调度器与系统时钟。
- **资源配置**：根据用户参数分配堆（Heap）内存与任务优先级。
- **系统复位/释放**：提供反初始化接口，用于安全地停止所有服务并释放占用的硬件资源，通常用于 OTA 升级前或系统关闭流程。
