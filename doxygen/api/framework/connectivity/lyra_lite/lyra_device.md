# Lyra Lite 设备管理 API 开发指南

**Lyra Lite 设备管理 (Device Management)** 模块负责全生命周期的设备连接与状态维护。

在通过“广播与发现”模块识别到目标设备后，本模块接管后续的交互流程，包括发起连接、建立安全的配对（Pairing）与绑定（Bonding）关系、管理连接参数以及处理连接断开等事件。它是实现设备间稳定数据传输的控制中心。

## 1. 接口概览

本模块的接口主要围绕 **设备对象 (Device Object)** 进行操作，涵盖以下核心功能：

- **连接管理**：发起连接请求 (Connect) 与断开连接 (Disconnect)。
- **安全管理**：处理配对请求、输入密钥、确认绑定状态及加密链路建立。
- **信息查询**：获取远端设备的基本信息（如设备名称、MAC 地址、MTU 大小、连接间隔等）。
- **事件回调**：注册连接状态变更或安全状态变更的监听器。
