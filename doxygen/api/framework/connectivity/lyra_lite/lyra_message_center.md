# Lyra Lite 一对多消息中心 API 开发指南

**Lyra Lite 一对多消息中心 (One-to-Many Message Center)** 模块旨在解决中心设备（Central）同时与多个远端设备（Peripheral）进行高效数据交互的复杂性。

在多连接拓扑结构中，本模块作为数据通信的枢纽，向上层应用屏蔽了具体的连接句柄管理，提供了一套统一的消息调度、分发（Unicast/Multicast）与数据汇聚机制。它确保消息能够准确地路由到指定的一个或多个设备，并异步处理来自不同设备的回应。

## 1. 接口概览

本模块的核心功能围绕消息的**路由 (Routing)** 与 **调度 (Dispatching)** 展开，主要包括：

- **消息发送**：支持向特定设备发送单播消息，或向所有已连接设备发送广播/组播消息。
- **消息接收**：提供统一的回调接口，处理来自不同设备上报的数据，并携带设备标识以便区分数据来源。
- **队列管理**：在多设备并发通信时，内部维护消息发送队列，避免拥塞导致的数据丢失。
