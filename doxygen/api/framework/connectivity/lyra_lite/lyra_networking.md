# Lyra Lite 组网管理 API 开发指南

**Lyra Lite 组网管理 (Networking)** 模块提供了构建和维护设备网络的高级抽象机制。

与简单的点对点连接不同，本模块专注于**网络拓扑 (Network Topology)** 的建立与维护。它负责处理节点的自动发现、加入网络请求、网络角色的分配（如中心节点与边缘节点）以及网络状态的自我修复。通过该模块，应用层可以将一组设备视为一个整体网络进行管理，而无需关注底层的连接握手细节。

## 1. 接口概览

本模块的接口旨在简化网络生命周期的管理，核心功能包括：

- **网络构建**：配置网络参数（如网络ID、最大节点数），启动或停止网络服务。
- **成员管理**：处理新设备的入网请求、踢出设备以及维护当前在线节点列表。
- **状态维护**：监控网络的整体健康状况，处理节点意外掉线后的重连或网络拓扑更新事件。
- **角色配置**：定义当前设备在网络中的角色（例如作为网络协调者或普通终端节点）。

### 1.1 组网管理接口 (Networking API)
