# 数字车钥匙 API (Digital Key API)

**数字车钥匙 API (Digital Key API)** 模块提供了连接子系统中车辆出入与权限管理的编程接口。该模块利用蓝牙 (BLE)、NFC 或 UWB 等短距离通信技术，支持将智能手机或可穿戴设备转化为虚拟汽车钥匙，实现无感进入、启动引擎及远程控制等功能。

本 API 旨在屏蔽底层不同通信标准（如 ICCOA, CCC, ICCE）的差异，为上层业务应用提供统一、安全的钥匙管理与控制接口。

## 模块功能与架构

Digital Key API 主要涵盖以下功能领域的接口：

1. **多标准适配接口**：支持接入主流的数字钥匙联盟标准。目前的文档重点涵盖了 **ICCOA (智慧车联开放联盟)** 标准的 API 实现。
2. **安全鉴权接口**：处理设备与车辆之间的双向身份认证、密钥交换及安全通道建立。
3. **指令处理接口**：负责接收来自移动终端的控制指令（如解闭锁、升窗、寻车），并将其解析为车载网络可识别的控制信号。
