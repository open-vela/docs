# 数字车钥匙 ICCOA 协议接口 (DKF ICCOA API) 开发指南

**DKF ICCOA API** 模块是数字车钥匙框架（Digital Key Framework, DKF）中针对 **ICCOA（智慧车联开放联盟）** 标准的具体实现层。

该模块旨在为系统提供符合 ICCOA 规范的数字钥匙能力，确保车辆能够与支持 ICCOA 标准的移动终端（如各大品牌的安卓手机）进行安全、高效的交互。它充当了通用车钥匙逻辑与特定联盟标准之间的适配桥梁。

该模块的主要职责包括：

- **协议栈适配**：实现 ICCOA 标准定义的通信流程、数据包格式及加密规范。
- **业务逻辑映射**：将 ICCOA 的指令（如闭锁、解锁、启动引擎）转换为系统内部通用的控制命令。
- **鉴权与配对**：处理符合 ICCOA 规范的设备配对、证书验证及身份鉴权流程。
- **状态管理**：维护当前 ICCOA 连接的会话状态及钥匙生命周期。

## 1. API 接口概览

`dkf_iccoa_api.h` 定义了上层应用或 DKF 核心层调用 ICCOA 能力的统一接口。

- **核心功能**：

    - **初始化与配置**：设置 ICCOA 协议栈参数，注册必要的系统回调。
    - **指令处理**：发送和接收标准化的 ICCOA 消息。
    - **事件上报**：定义了通过回调函数上报的协议栈事件（如连接建立、鉴权通过、异常断开）。
    - **能力查询**：查询当前实现支持的 ICCOA 版本及具体功能特性。
