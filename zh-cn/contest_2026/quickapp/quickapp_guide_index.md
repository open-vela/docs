# 快应用教程导航

> 本页面是 openvela AI 硬件开发者大赛「快应用」相关教程的总入口，帮助参赛者快速找到所需文档。

## 教程列表

| 教程                                                                        | 说明                                                                                                                             |
| --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| [快应用开发指南（手动开发）](./quickapp_manual.md)                          | 手动创建项目、编写代码、打包、部署到模拟器/开发板、提交参赛的完整流程。适合熟悉前端开发、希望精细控制代码的参赛者。              |
| [快应用开发指南（AI 工作流）](./quickapp_ai_workflow.md)                    | 使用 Claude Code + VelaJS MCP 实现从需求描述到代码生成到模拟器调试的全流程自动化。适合希望快速出原型、让 AI 代劳写代码的参赛者。 |
| [openvela 快应用调用 velaclaw（端侧 AI Agent）教程](./quickapp_velaclaw.md) | 在快应用中通过 `@system.velaclaw` 调用端侧 AI Agent 能力（如自然语言问答）。适合需要在应用中集成 AI 对话功能的参赛者。           |
| [支持的硬件平台](../hardware_porting/supported_hardware.md)                 | 大赛提供的开发板清单（已支持 + 待适配），可选型号参考。                                                                          |

## 如何选择

- **我要从零开始手写一个快应用** → 看《手动开发》
- **我想让 AI 帮我生成代码** → 看《AI 工作流》
- **我的应用需要调用 AI 问答能力** → 看《velaclaw 教程》（需先完成前两者之一的环境搭建）

> 三篇教程可独立阅读，也可组合使用。例如：用 AI 工作流生成代码 → 参考手动指南部署到 openvela 模拟器 → 参考 velaclaw 教程集成 AI 对话能力。
