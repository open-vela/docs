# 在 STM32H750 开发板上部署 openvela

## 一、概述

本文档旨在指导如何在 STMicroelectronics STM32H750 微控制器开发板（STM32H750）上部署 openvela，并基于 openvela 操作系统运行 Light and Versatile Graphics Library（LVGL）图形库的演示程序（Demo）。

## 二、准备工作

### 1、搭建开发环境

1. 配置编译环境：

    编译 openvela 需要配置相关的开发环境，详情请参见[设置开发环境](https://github.com/open-vela/docs/blob/dev/zh-cn/quickstart/Set_up_the_development_environment_zh-cn.md)。

2. 安装编译工具：

    ```Bash
    sudo apt install gcc-arm-none-eabi binutils-arm-none-eabi
    ```

3. 软件下载：

    1. 下载安装 STM32CubeProgrammer 工具，该工具用于烧录程序。下载地址为 [STM32CubeProgrammer 官方下载链接](https://www.st.com/en/development-tools/stm32cubeprog.html)。

    2. 安装完成后，执行如下命令安装 libusb，该库用于连接 USB 设备：

        ```C++
        sudo apt-get install libusb-1.0.0-dev 
        ```

    3. 下载 [stsw-link](https://www.st.com/en/development-tools/stsw-link007.html#get-software) 软件包并解压，解压后可获得相关的驱动文件适配您的平台。根据压缩包中的 `readme.txt` 文件指引完成安装。以下是具体的安装命令：

        ```Bash
        sudo sh st-stlink-udev-rules-xxxx-linux-noarch.sh
        ```

        ![img](./figures/018.png)

    4. 启动后界面如下：

        ![img](./figures/005.png)

### 2、连接开发板

1. 使用 **USB** 数据线将开发板的 **ST-Link** 调试接口连接到上位机，如下图所示：

    ![img](./figures/006.png)

2. 启动 STM32CubeProgrammer，点击红框处**刷新**按钮，如果 **Serial number** 下拉框出现数字序列，表示已成功检测到开发板。

    ![img](./figures/007.png)

3. 在左侧导航栏选择 **Erasing & Programming**，如下图所示：

    ![img](./figures/008.png)

4. 选择 **ST-LINK** 方式，点击绿色 **Connect** 按钮。当按键变为 **Disconnect** 时，表示开发板已成功连接，如下图所示：

    > 说明
    >
    > **ST-LINK** 的说明文档请参见[官方文档](https://www.st.com/resource/en/technical_note/tn1235-overview-of-stlink-derivatives-stmicroelectronics.pdf)。

    ![img](./figures/009.png)

## 三、运行 Demo

### 1、下载代码

参考[下载 openvela 源代码](https://github.com/open-vela/docs/blob/dev/en/quickstart/Download_Vela_sources.md)完成代码下载。

### 2、编译代码

在代码仓库下载完成后，按照以下步骤为 **STM32H750B-DK** 开发板编译所需的二进制文件：

```Bash
# 进入 nuttx 根目录  
cd nuttx

# 配置开发板环境  
./tools/configure.sh -l stm32h750b-dk:lvgl

# 在运行 make 编译前，可使用 make menuconfig 命令修改配置，确保所需的功能模块已经启用（如示例中的 LVGL Demo）

# 开始编译 
make
```

编译完成后，生成的文件位于 `nuttx` 目录下，包括：

- `nuttx.bin`
- `nuttx.hex`

    ![img](./figures/010.jpg)

### 3、运行程序

1. 打开上一步安装的 **STM32CubeProgrammer** 工具。

2. 选择需要下载的二进制文件，即上一步编译生成的 `nuttx.hex` 文件，并勾选 **Skip flash erase before programming**，如下图所示：

    ![img](./figures/011.png)

3. 单击 **Start Programming** 按钮开始下载。下载完成后，会弹出提示框，并且日志窗口会输出相关信息。

    ![img](./figures/012.png)

4. 使用串口工具（如 **Minicom** 或 **Tera Term**）连接并访问开发板，以下以 Minicom 为例，使用如下命令：

    ```Bash
    sudo minicom -D /dev/ttyACM0 -b 115200
    ```

5. 在 Minicom 串口终端中执行文件系统查看命令，具体操作如下：

    1. 首次使用 Minicom 的配置事项：如果无法接收键盘输入，请修改 Minicom 的相关配置。

    2. 使用以下命令打开 Minicom 配置界面：

        ```Bash
        sudo minicom -s
        ```

        ![img](./figures/013.png)

    3. 进入 Serial port setup 配置目录，确保以下两项配置值为 No：

        - Hardware Flow Control: No
        - Software Flow Control: No

        ![img](./figures/014.png)

    4. 配置完成后重新打开 Minicom。如果仍无法输入，请尝试按下开发板上的黑色按键，重新上电后再打开 Minicom。

        ![img](./figures/015.png)

6. 输入以下命令运行示例程序：

     ```Bash
    lvgldemo
    ```

    ![img](./figures/016.png)

7. 示例程序运行结果如下图所示：

    ![img](./figures/017.png)

## 四、开发板简介

[STM32H750XB](https://www.st.com.cn/zh/microcontrollers-microprocessors/stm32h750xb.html#documentation) 是一款基于 Arm Cortex-M7 内核的高性能微控制器，集成 DSP、DP-FPU、128 KB 闪存、1 MB RAM，以及外部存储接口、硬件加密和丰富外设，主频高达 480 MHz，适用于工业自动化和物联网设备。

1. 开发板正面。

2. 开发板背面。

    ![img](./figures/002.png)

### 2、主要硬件特性

- 基于 Arm® Cortex® 内核的微控制器，有以下存储选项：

    - 具有 128 Kbytes (STM32H750XBH6) 闪存和 1 Mbyte 的 RAM。
    - 采用 TFBGA240+25 封装。

- 4.3 英寸 RGB 接口 LCD， 配备触摸面板连接器。
- 符合 IEEE-802.3-2002 标准的以太网接口，支持以太网供电（PoE）。
- USB OTG FS 接口。
- SAI 音频编解码器。
- 一个 ST-MEMS 数字麦克风。
- 2× 512-Mbit Quad-SPI NOR 闪存。
- 128-Mbit SDRAM。
- 4-Gbyte 片载 eMMC 存储器。
- 一个用户按键和复位按键。
- 扩展子板（Fanout Daughterboard）。
- 2× CAN FD 接口。
- 板载连接器：

    - USB FS Micro-AB 连接器。
    - ST-LINK Micro-B USB 连接器。
    - USB 电源 Micro-B 连接器。
    - Ethernet RJ45 接口。
    - 立体声耳机插孔（包括模拟麦克风输入）。
    - 外部扬声器音频插针接口。
    - Tag-Connect™ (TAG) 10 针接口焊盘。
    - Arm® Cortex® 10 针 （1.27 mm 间距）调试连接器（通过 STDC14 焊盘）。
    - ARDUINO® Uno V3 扩展连接器。
    - STMod+ 扩展接口。

- 灵活的电源选项：
    - STLINK-V3E USB 连接器和 USB FS 连接器。
    - 通过 RJ45 提供的 5 V 电源（PoE）。
    - 通过 ARDUINO® 或外部连接器提供的 5 V 电源。
    - USB 充电器。
    - USB 电源。

- 板载 STLINK-V3E 调试器/编程器，具有以下功能：

    - USB 重新枚举功能。
    - 大容量存储支持。
    - 虚拟串口（Virtual COM Port）。
    - 调试端口。

- 支持多种集成开发环境 (IDEs)，包括：
    - IAR Embedded Workbench®
    - MDK-ARM
    - STM32CubeIDE
