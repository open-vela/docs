# openvela 外设驱动总览

\[ [English](../../../../en/device_dev_guide/driver/peripheral_driver/peripheral_drivers_overview.md) | 简体中文 \]

openvela 提供一套丰富且标准化的外设驱动框架，旨在简化底层硬件的访问和管理。该框架通过统一的 API，支持多种常见外设，帮助开发者快速构建上层应用。

下表对 openvela 支持的主要外设驱动进行了分类和说明：

| **驱动类别**       | **驱动名称** | **英文全称 / 缩写**                 | **功能描述**                                                         |
| :----------------- | :----------- | :---------------------------------- | :------------------------------------------------------------------- |
| **系统核心与总线** | 直接内存访问 | DMA (Direct Memory Access)          | 在不占用 CPU 的情况下，实现外设与内存之间的高速数据传输。            |
|                    | 引脚控制     | Pinctl (Pin Control)                | 统一管理和配置芯片引脚的功能复用与电气特性（如上下拉、驱动强度）。   |
| **安全与随机性**   | 随机数生成器 | RNG (Random Number Generator)       | 提供硬件接口，生成用于加密、安全协议等场景的真随机数或伪随机数。     |
|                    | 加密引擎     | Crypto (Cryptography)               | 利用硬件加速对称/非对称加密、哈希计算等密码学操作。                  |
| **数据处理与加速** | 硬件加速器   | Accel (Accelerator)                 | 用于卸载 CPU 密集型计算任务，如图形处理或 AI 运算。                  |
| **模拟与转换**     | 模拟信号处理 | Analog                              | 包含 ADC (模数转换器) 和 DAC (数模转换器) 等驱动，用于处理模拟信号。 |
| **通用接口**       | 通用输入输出 | GPIO (General-Purpose Input/Output) | 控制引脚的电平状态（高/低），实现基本的数字信号输入与输出。          |
| **传感器与定位**   | 传感器       | Sensor                              | 为各类传感器（如加速度计、陀螺仪、温湿度计）提供统一的访问接口。     |
|                    | 全球定位系统 | GPS (Global Positioning System)     | 解析来自 GPS 模块的定位数据，获取经纬度、速度等地理空间信息。        |
| **人机交互**       | 振动器       | Vibrator                            | 控制振动马达，为用户提供触觉反馈。                                   |
|                    | 红外通信     | IR (Infrared)                       | 实现红外信号的发送与接收，常用于遥控等应用。                         |
| **无线通信**       | 近场通信     | NFC (Near Field Communication)      | 支持设备在短距离内进行非接触式数据交换和识别。                       |

后续章节将详细介绍上述各类驱动的实现细节、配置方法与 API 使用指南。
