# 内存管理

\[ [English](../../../../en/device_dev_guide/kernel/memory_management/memory_mgt.md) | 简体中文 \]

## 一、简介

openvela 的内存管理模块代码位于 `nuttx/mm` 目录下，该目录包含了内存管理相关的模块。这些模块提供了内存分配、内存映射、共享内存管理等功能，以支持系统和应用程序的内存需求。

## 二、目录结构

`mm`目录实现了 openvela 的内存管理单元逻辑，主要包括以下目录：

```cpp
mm/
├── binfmt
├── kmm
├── mm_gran
├── iob
├── map
├── pgalloc
├── pool
├── shm
├── tlsf
└── umm
```

## 三、各模块简介

### 1、binfmt

`binfmt` 模块用于处理不同格式的可执行文件的加载和执行。它支持 ELF 等常见的可执行文件格式。

### 2、kmm

`kmm` 模块提供了内核态的内存管理功能，支持内核态的内存分配和释放。

### 3、mm_gran

`mm_gran` 模块实现了粒度内存分配器，用于管理小块内存的分配和释放。

### 4、iob

`iob` 模块用于管理输入输出缓冲区，提供了一种高效的方式来处理网络数据包、串口数据等需要缓冲的数据。

### 5、map

`map` 模块用于管理内存映射，支持进程间共享内存和设备内存映射等功能。

### 6、pgalloc

`pgalloc` 模块实现了页面分配器，用于管理大块内存的分配和释放。

### 7、pool

`pool` 模块实现了内存池分配器，通过预分配的内存块来提高内存分配和释放的效率。

### 8、shm

`shm` 模块用于管理共享内存，支持进程间的内存共享。

### 9、tlsf

`tlsf` 模块用于内存管理，等同于Default heap manager。

### 10、umm

`umm` 模块提供了用户态的内存管理功能，支持用户态的内存分配和释放。
